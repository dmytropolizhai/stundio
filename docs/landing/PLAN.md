# Landing page — архитектурный план

Mobile-first лендинг для рекламы Stundio. Этот файл — единый источник правды для субагентов:
статус задач, решения, входы/выходы, правила. Каждый агент обновляет свою строку статуса.

## Роли

| Роль | Кто | Почему |
| --- | --- | --- |
| Архитектор / координатор | основной агент (Sonnet 5.5) | декомпозиция, документация, ревью, склейка |
| Стратегия, ЦА, IA, дизайн-система, компонентная библиотека | Opus 5.5 | сложные решения, на которых стоит всё остальное |
| Исследование, копирайт, реализация по готовой спеке | Sonnet 5.5 | хорошо исполняет чётко заданное |
| Механические задачи (аудит ассетов, чеклисты, линт) | Haiku 4.5 | дёшево и быстро |

## Входные факты (обязательны к прочтению)

`README.md`, `PRODUCT.md`, `AGENT.md`, `DESIGN.md`, `src/ds/tokens/`, `.github/assets/`.

Нюансы, на которых агенты не должны ошибиться:

- **README новее PRODUCT.md.** В PRODUCT.md написано «no real users yet» — устарело. Актуально по
  README: 200+ пользователей (включая учителей), 1.1k уникальных визитов / 2k всего, Android > iOS.
  Это единственные разрешённые цифры. Не округлять вверх, не выдумывать.
- **Нет Google Play и не будет** (юридический риск). Установка: APK с GitHub Releases через
  `stundio.pages.dev/download`; iOS/desktop — PWA («Добавить на экран Домой»).
- **Запрещено выдумывать:** отзывы, рейтинги, логотипы школ, упоминания прессы, скриншоты,
  которых нет. Реальные скриншоты — `.github/assets/screenshots/*.png`.
- Не аффилирован с RVT / EduPage / aSc — дисклеймер обязателен (см. README «License»).
- Ценностное предложение = виджет + офлайн + без логина + подмены на месте урока.
- Языки приложения: LV, EN, RU, UA. Язык лендинга — решает задача 1 (рекомендация с обоснованием).
- Приватность: без аккаунтов, Plausible opt-out, ничего не уходит с устройства.
- Не использовать эмодзи/юникод-символы как иконки.

## Решения по умолчанию (оспариваются только с обоснованием)

- Ветка `feat/landing-page`, затем PR (AGENT.md → Changes).
- Лендинг — статическая страница, живёт в `landing/` рядом с приложением, **не** в `src/`
  (не ломает coverage-пороги и правила слоёв приложения). Окончательную форму сборки
  (отдельный Vite entry vs. подпапка) выбирает задача 3.
- Визуально наследует Studio Design System (`src/ds/tokens`), шрифты Manrope + JetBrains Mono.
  Отступление допустимо только если ЦА-исследование докажет, что лендингу нужен другой тон, —
  и оформляется как явное решение в `03-design-direction.md`.
- Mobile-first: проектируем на 360–390 px, затем расширяем. Основной трафик — Android.
- Utility wins: быстрый LCP, мало JS, работает на слабой сети.

## Правила для всех агентов

1. Пиши в свой выходной файл, не трогай чужие и не трогай `src/`, `android/`, `functions/`.
2. Любое утверждение о продукте — со ссылкой на источник в репозитории. Нет источника → в «не утверждать».
3. Не коммить. Коммитит архитектор.
4. В конце — краткий отчёт: что сделано, какие решения приняты, какие вопросы остались.
