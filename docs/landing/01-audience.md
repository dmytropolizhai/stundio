# Целевая аудитория лендинга — синтез

Сводка трёх исследований. Детали и доказательства: `01a-segments.md`, `01b-alternatives.md`,
`01c-claims-and-voice.md`. При расхождении побеждает детальный документ.

## Для кого

| Приоритет | Сегмент | Роль в лендинге |
| --- | --- | --- |
| S1 | Студенты RVT на Android | Ядро. Есть виджет, самый высокий барьер установки (APK, «неизвестный источник») |
| S2 | Студенты на iPhone и с компьютера | PWA-инструкция, честное «виджеты только на Android» |
| S3 | Учителя (Teacher Mode) | Один блок, без отдельной страницы |
| S4 | Первокурсники | Не сегмент, а момент внутри S1/S2: два здания, кабинеты |
| S5 | Родители | Не проектируем |
| S6 | Оценивающие работу автора | Только качество страницы и ссылка на GitHub в футере |

Принцип из PRODUCT.md: **utility wins**. Когда польза ученика и впечатление для портфолио
расходятся, побеждает польза.

## Первые 5 секунд

Почти все приходят по рекомендации, с телефона, часто из встроенного браузера мессенджера.
Первый экран без скролла должен сказать: это расписание RVT, «сейчас / дальше» без сети и без
логина. На нём одна кнопка под устройство и короткая подпись против главного страха
(«не из Play Store»).

## Ключевые сообщения (по убыванию важности)

1. «Сейчас / дальше» без сети; на Android виджетом.
2. Замены показаны на месте урока.
3. Без логина и без данных о тебе.
4. Не из Play Store: открытый код, обновляется само.
5. Уже пользуются 200+ человек, включая учителей (самоотчёт README, формулировать осторожно).

## Что нельзя говорить

Отзывы, рейтинги, Google Play и App Store, связь с RVT/EduPage/aSc, «быстрее EduPage в N раз»,
«100% офлайн», «без трекинга», виджеты на iOS, e-klase. EduPage упоминаем нейтрально, как
источник расписания. Цифры 1.1k и 2k относятся к веб-версии и на лендинг не выносятся.

## Язык и тон

LV, RU, EN, UA; по умолчанию LV (предположение). Автоопределение по `navigator.languages` один
раз, затем видимый переключатель с названиями языков на своём языке, без флагов. Короткие
глагольные фразы без маркетингового пафоса.

## Открытые вопросы к автору

1. **QR и текст на карточке «поделиться неделей» ведут на `https://bit.ly/stundio`**
   (`src/ui/share/weekImage.ts:35`). Вести ли его на лендинг? От этого зависит, как страница
   встречает пришедших по QR.
2. Можно ли называть RVT на лендинге вне дисклеймера (юридический вопрос).
3. Подпись «Better EduPage experience» (`share.image.appLabel`, `share.message`) может читаться
   как связь с EduPage. Оставить, переписать?
4. Реального скриншота виджета на домашнем экране нет. Главный аргумент для Android остаётся без
   картинки; нужна съёмка (см. `02c-assets.md`).
5. Баги в приложении, замеченные по ходу: `LANG_NAMES.ua = "Солов'їна"` (`src/ui/i18n/index.ts:17`);
   «учитель» и «преподаватель» смешаны в RU/UA.
6. README и PRODUCT.md расходятся с кодом (13 пунктов в `01c`): например, отзывы уходят в
   Web3Forms, а README пишет «без сторонних форм»; push-функция хранит метку класса или хеш
   учителя. Лендинг опирается на код, а не на README.
