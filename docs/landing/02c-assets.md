## 2. Что не хватает для лендинга

Для полноценного рекламного лендинга (по требованиям PLAN.md и PRODUCT.md) нужны скриншоты:

### A. **Widget примеры на домашнем экране Android** (3 шт.)
Зачем: покажут интеграцию с экосистемой, convenience factor.

Описание виджетов (из `android/app/src/main/res/values/widget.xml`):
1. **"Nākamā stunda"** (Next lesson) — текущий + следующий урок в real-time
2. **"Laiks līdz beigām"** (Countdown) — таймер до конца/начала урока
3. **"Šodiena"** (Today) — все уроки дня в списке

Что снять:
- Три разных примера расположения виджетов на Android home screen
- Разные размеры (4×2, 4×1, 2×2 или другие)
- Темная тема (если не существует, то 1 скриншот — достаточно)
- Язык: **LV** (по умолчанию для примера), **EN/RU** опционально
- Размер: 360–390 px ширина (mobile-first)

## 3. Рекомендации по оптимизации

### Форматы
- **Текущие**: PNG, SVG, ICO
- **Рекомендуемые для лендинга**:
  - **WebP**: для скриншотов (90% качество) — экономия ~30% от PNG
  - **AVIF** (fallback WebP): для совместимости новых браузеров (~10% экономии от WebP)
  - **SVG**: для логотипа и иконок (уже правильно)
  - **ICO/PNG**: оставить для favicon (для браузеров)

### Размеры скриншотов
- Текущие скриншоты: 253×522 px (узкие, мобильные)
- **Для лендинга**: оптимально 360–390 px ширина (типичный мобильный экран)
  - Если делать wider: есть два варианта—
    - 480–540 px (для планшетов, desktop) — нужны отдельные скриншоты
    - или просто масштабировать 253×522 (потеря качества)
  - **Рекомендация**: оставить 253×522 как есть (mobile-first), в дизайне лендинга масштабировать CSS

### Ленивая загрузка (lazy loading)
- Скриншоты на лендинге: `loading="lazy"` для `<img>`
- Иконки выше折 (fold): `loading="eager"`
- WebP с fallback на PNG через `<picture>` или `srcset`

### Оптимизация размеров файлов (уже хорошие)
- Скриншоты PNG: 63–127 KB — нормально для мобильного
  - При переходе на WebP: ~45–90 KB
  - При AVIF: ~30–60 KB
- Иконки: 3–11 KB — отлично

### Пример разметки для лендинга
```html
<picture>
  <source srcset="/img/week-view.avif" type="image/avif">
  <source srcset="/img/week-view.webp" type="image/webp">
  <img src="/img/week-view.png" alt="Nākamā stunda — weekly view" 
       loading="lazy" width="253" height="522">
</picture>
```

### CDN и кеширование
- Долгосрочный кеш (Cache-Control: max-age=31536000) для иконок с хешем в имени
- Скриншоты: стандартный кеш (max-age=3600–86400)
- Сжатие gzip/brotli на сервере
